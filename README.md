# birdee 0.2 Universal

Ücretsiz, sunucusuz PWA prototipi.

## Özellikler
- Serbest plan oluşturma
- Gün / saat / kategori / hedef / birim
- Kısmi ilerleme yüzdesi
- Günlük skor
- Kırmızı → sarı → koyu yeşil performans takvimi
- Son 7 gün ve kategori istatistikleri
- Gün sonu 1–10 puan + not
- JSON veri dışa aktarma
- Offline PWA cache
- iPhone ve Mac için responsive arayüz

## Veri
Prototip verileri localStorage içinde kullanıcının cihazında tutulur. Bu sürümde hesap ve bulut senkronizasyonu yoktur.

## Mac
900px ve üzerindeki ekranlarda Birdee otomatik olarak masaüstü düzenine geçer.
